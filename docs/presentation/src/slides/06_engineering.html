Field Reliability
Robotics is the art of fighting real-world physics. Theory guarantees nothing until hardware survives the elements and edge-case network loads.
FastDDS UDP Buffer Storm
KERNEL SYSCTL
Problem: Linux default 212 KB UDP socket buffer choked under high-frequency SLAM map exchanges. Cascading retransmissions caused 100% CPU lockup.
Fix: net.core.rmem_max = 67108864 (64 MB socket buffer) in /etc/sysctl.d/99-ros2-fastdds.conf.
Wheel Velocity & Stiction Calibration
MICRO-ROS REGRESSION
Problem: DC gearmotors exhibit non-linear friction deadbands; left and right motors had different starting torque thresholds.
Fix: Automated velocity sweep ($PWM = k \cdot v + b$) in helpers/wheel_calibration embedded into firmware.
5 GHz Wi-Fi Region Lockdown on Pi 5
HOST WIRELESS
Problem: Raspberry Pi 5 kernel defaulted to country 99 (DFS-UNSET), disabling 5 GHz bands and throttling camera stream.
Fix: Configured persistent regulatory domain unlocking Channel 52 for low-latency RTSP camera streams.
AI Agent Context & Reasoning Latency
SESSION LIFECYCLE
Problem: Expired chat session IDs crashed CLI; raw <think> tokens introduced 10–20s delays before speech playback.
Fix: Dynamic session renewal, reasoning token suppression (<50ms TTFT), and RAM model pre-warming.
