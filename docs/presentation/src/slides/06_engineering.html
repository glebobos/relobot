Learning by Doing
Real robotics is learned on the bench and in the grass. Theory guarantees nothing until code survives physical friction, socket buffers, and real-world edge cases.
FastDDS UDP Buffer Storm
KERNEL SYSCTL
Hurdle: Default Linux 212 KB socket buffer choked under high-rate SLAM maps, triggering retransmission storms and 100% CPU lockup.
Fix: net.core.rmem_max = 67108864 (64 MB buffer) in sysctl.
Motor Stiction Non-Linearity
FIRMWARE REGRESSION
Hurdle: DC gearmotors had asymmetrical starting friction deadbands, causing low-speed angular drift.
Fix: Automated linear sweep ($PWM = k \cdot v + b$) in RP2040 firmware.
5 GHz Wi-Fi Region Lockdown
HOST WIRELESS
Hurdle: Pi 5 kernel defaulted to DFS-UNSET, blocking 5 GHz channels and throttling camera streams.
Fix: Configured persistent regulatory domain unlocking Channel 52 for RTSP.
AI Agent Context & Reasoning
SESSION LIFECYCLE
Hurdle: Raw thinking tokens introduced 10–20s delays before voice speech started.
Fix: Suppressed reasoning tokens (<50ms TTFT) and pre-warmed model graph in RAM.
