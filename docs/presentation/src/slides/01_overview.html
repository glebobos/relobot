RELOBOT / SYSTEM OVERVIEW

ReloBot Platform Architecture

An end-to-end robotics platform born from learning real-world robotics from scratch — combining micro-ROS, containerized ROS 2, and edge AI.

Engineering Journey
Started as a hands-on journey to learn real robotics from first principles — motor physics, microcontrollers, and ROS 2. It naturally evolved into a full-scale autonomous platform with on-device AI.
Hardware-Isolated Real-Time Core
MICRO-ROS
Real-time motor control, safety watchdogs, and sensor loops run on dedicated microcontrollers — fully decoupled from high-level software crashes.
Containerized ROS 2 & Digital Twin
DOCKER · GAZEBO
Zero host pollution with shared-memory IPC, paired with 100% topic, TF, and physics parity inside Gazebo simulation for risk-free testing.
100% On-Device AI Autonomy
AGY · PIPER TTS
Onboard agent platform (AGY) and sub-100ms local neural voice synthesis (Piper) running entirely on Raspberry Pi 5 without cloud reliance.
