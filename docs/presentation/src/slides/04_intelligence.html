The Self-Aware Robot: AGY Core

Natural language chat is just the operator interface — AGY is an extensible on-device agent platform.

Why Run Locally on Pi 5?
Robots lose Wi-Fi in the yard all the time. Critical diagnostics, sensor reasoning, and spoken operator feedback must function autonomously without waiting for a cloud round-trip.
RoboFactory AGY Agent Platform
AGY RUNTIME
  • Onboard Runtime: Google Antigravity & AGY agent executed inside the ros2_voice_chat container.
  • Full Introspection: Direct programmatic access to FastDDS telemetry, ROS 2 parameters, topic streams, and container logs.
  • Beyond Chat: Natural language is just the operator UI; AGY's primary role is proactive system oversight and automated fault detection.
  • Extensible Hooks: Evolving toward automated node restarts, PID parameter tuning, and multi-robot swarm task allocation.
Piper Neural Voice Pipeline
LOCAL TTS
  • Sub-100ms Latency: Local neural speech synthesis running purely on Raspberry Pi 5 CPU cores with zero cloud dependencies.
  • Pipelined Token Streaming: Regex punctuation chunking allows audio playback to start while the LLM is still generating tokens.
  • Concurrent Audio Out: Simultaneous broadcast to physical robot chassis speaker and operator browser Web Audio.
  • Engineering Persona: Tuned for concise, razor-sharp technical diagnostics and status reports.
