Field Engineering

Hard Problems Solved

Real battle-tested lessons from assembling and running autonomous robotics.

⚡ FastDDS Buffer Storm
  • Problem: Linux default 212 KB socket buffer choked on large SLAM maps, creating cascading NACK retry loops & CPU freeze.
  • Solution: Tuned host kernel buffers to 64 MB (net.core.rmem_max = 67108864).
📐 Wheel Velocity & Stiction Calibration
  • Problem: DC motors exhibit non-linear deadbands and friction differences between left and right wheels.
  • Solution: Automated velocity sweep & linear regression ($PWM = k \cdot v + b$) in helpers/wheel_calibration.
📡 5 GHz Wi-Fi on Raspberry Pi 5
  • Problem: Pi 5 defaults to country 99 (DFS-UNSET), blocking 5 GHz high-speed channels.
  • Solution: Host regulatory configuration unlocking Channel 52 for lag-free video streams.
🧠 AI Agent Context & Session Reliability
  • Problem: Preserved expired session IDs crashed CLI; LLM reasoning tokens delayed speech by 10–24s.
  • Solution: Dynamic session lifecycle tracking, <think> token suppression (<50ms TTFT), and RAM model pre-warming.
