SOFTWARE ARCHITECTURE / DIGITAL TWIN

Containerized ROS 2 & Gazebo Simulation

Zero host pollution with shared-memory IPC, paired with 100% API parity in the virtual digital twin.

Why Docker & Simulation?
Fast iteration without breaking the host OS. Docker and Gazebo simulation enabled safe, rapid learning of ROS 2 navigation before running physical hardware.
Multi-Container ROS 2 Architecture
DOCKER RUNTIME
  • Host Purity: Host OS only runs Docker and serial device mounts. No ROS packages installed on host.
  • Zero Latency Transport: network_mode: host and ipc: host enable FastDDS shared memory communication.
  • Volume Hot-Reloading: Workspace source mounted directly; node rebuilds and web changes take effect immediately.
  • Standard ROS 2 Interfaces: Uses ros2_control, robot_localization EKF, and standard Nav2 behavior trees.
ros2_nav2 · ros2_voice_chat · ros2_rosbridge · ros2_frontend
Zero-Risk Gazebo Digital Twin
SIMULATION
  • 100% API Parity: Identical topic names (/cmd_vel, /scan), TF frames, and Nav2 action servers.
  • Physics & Friction Models: garden.sdf includes real lawn friction parameters, perimeter obstacles, and rough terrain.
  • Emulated Sensors: Simulated 360° laser scans, synthetic camera feeds, and blade motor speed feedbacks.
  • Instant Laptop Launch: ./start_sim.sh up --gui --dev tests the entire autonomy pipeline on a laptop.
Saved ~3 weeks of bench testing before running physical blades.

ON-DEVICE AI / AGENT PLATFORM

The Self-Aware Robot: AGY Core

Autonomous onboard reasoning engine with native ROS 2 introspection and sub-100ms neural voice.

Why Run Locally on Pi 5?
Robots lose Wi-Fi in the yard all the time. Critical diagnostics, sensor reasoning, and spoken operator feedback must function autonomously without waiting for a cloud round-trip.
RoboFactory AGY Agent Platform
AGY RUNTIME
  • Onboard Runtime: Google Antigravity & AGY agent executed directly inside the ros2_voice_chat container.
  • Full Introspection: Programmatic access to FastDDS telemetry, ROS 2 parameters, topic streams, and container logs.
  • Proactive Oversight: Automated system diagnostics, runtime health monitoring, and proactive fault detection.
  • Extensible Brain: AGY acts as the robot's autonomous decision layer and self-healing supervisor.
Piper Neural Voice Pipeline
LOCAL TTS
  • Sub-100ms Latency: Local neural speech synthesis running purely on Raspberry Pi 5 CPU cores with zero cloud dependencies.
  • Pipelined Token Streaming: Regex punctuation chunking allows audio playback to start while tokens are still streaming.
  • Concurrent Audio Out: Simultaneous broadcast to physical chassis speaker and browser Web Audio.
  • Diagnostic Persona: Tuned for concise, razor-sharp technical diagnostics and operational alerts.

FIELD ENGINEERING / LESSONS LEARNED

Hard Problems Solved in the Field

Concrete engineering hurdles and battle-tested solutions from actual lawn deployments.

Learning by Doing
Real robotics is learned on the bench and in the grass. Theory guarantees nothing until code survives physical friction, socket buffers, and real-world edge cases.
FastDDS UDP Buffer Storm
KERNEL SYSCTL
Hurdle: Default Linux 212 KB socket buffer choked under high-rate SLAM maps, triggering retransmission storms and 100% CPU lockup.
Fix: net.core.rmem_max = 67108864 (64 MB buffer) in sysctl.
Motor Stiction Non-Linearity
FIRMWARE REGRESSION
Hurdle: DC gearmotors had asymmetrical starting friction deadbands, causing low-speed angular drift.
Fix: Automated linear sweep ($PWM = k \cdot v + b$) in RP2040 firmware.
5 GHz Wi-Fi Region Lockdown
HOST WIRELESS
Hurdle: Pi 5 kernel defaulted to DFS-UNSET, blocking 5 GHz channels and throttling camera streams.
Fix: Configured persistent regulatory domain unlocking Channel 52 for RTSP.
AI Agent Context & Reasoning
SESSION LIFECYCLE
Hurdle: Raw thinking tokens introduced 10–20s delays before voice speech started.
Fix: Suppressed reasoning tokens (<50ms TTFT) and pre-warmed model graph in RAM.
Field Hardening: 64MB Socket Buffers · Stiction Linearization · 5 GHz Wi-Fi Unlock · <50ms TTFT Voice
Every fix was paid for with a late-night debugging session.
