Hardware architecture / Hub & spoke

Hub & Spoke Micro-Agent Network

Physical separation of real-time control loops and central compute via dedicated USB CDC channels.

Why hardware isolation? Keeps real-time motor PWM and sensor acquisition isolated on dedicated MCUs. If higher-level software restarts, safety watchdogs and wheel loops never miss a cycle.

Field engineering / Lessons learned

Hard Problems Solved in the Field

Concrete engineering hurdles and battle-tested solutions from actual lawn deployments.

Learning by doing Real robotics is learned on the bench and in the grass. Theory guarantees nothing until code survives physical friction, socket buffers, and real-world edge cases.
Subsystem / incident Hurdle observed Intervention Evidence
Kernel sysctl

FastDDS UDP Buffer Storm

Default Linux 212 KB socket buffer choked under high-rate SLAM maps, triggering retransmission storms and 100% CPU lockup.

Set net.core.rmem_max = 67108864 in sysctl.

212 KB→64 MB
Firmware regression

Motor Stiction Non-Linearity

DC gearmotors had asymmetrical starting friction deadbands, causing low-speed angular drift.

Automated linear sweep in RP2040 firmware.

PWM = k · v + b
Host wireless

5 GHz Wi-Fi Region Lockdown

Pi 5 kernel defaulted to DFS-UNSET, blocking 5 GHz channels and throttling camera streams.

Configured persistent regulatory domain for RTSP.

Channel 52
Session lifecycle

AI Agent Context & Reasoning

Raw thinking tokens introduced 10–20s delays before voice speech started.

Suppressed reasoning tokens and pre-warmed model graph in RAM.

10–20s→<50ms TTFT
